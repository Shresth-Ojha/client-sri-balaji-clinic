# Sri Balaji Clinic — Landing Page

Landing page for Sri Balaji Clinic, Dr. Manoj Kumar Patel (Family
Physician), Kadabeesanahalli Main Road, Panathur, Bengaluru.

Plain HTML/CSS/JS, no build step — `index.html` is the entry point.
Same design system as the Shweta Clinic and Dr. Sumanjita Bora sites,
recolored to rose/pink, with the "What to expect" panel moved ahead of
services.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000
